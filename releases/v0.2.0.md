# email 0.2.0 — drafts, delivery history and real folder moves

This preview makes everyday IMAP/SMTP workflows more complete while keeping the
classic interface and German/English language support.

- Move real messages to Trash, Archive, Junk or another folder. Uses UID MOVE or a
  targeted UIDPLUS fallback, with UIDVALIDITY checks. No whole-folder expunge.
- Decode international IMAP folder labels and recognise SPECIAL-USE roles.
- Keep multiple local drafts with automatic saving and recovery after restart.
  Closing the app waits for the newest edit to be stored in redb.
- Save a durable record before SMTP submission. Accepted messages get an IMAP Sent
  copy, and a missing copy can be retried without another SMTP delivery.
- Review rejected and uncertain submissions in Local drafts & delivery. Ambiguous
  or interrupted sends are never resent automatically. Sent-copy retries check the
  original Message-ID before appending.
- Start from cached folders and messages, then reconnect with saved credentials.
  Accounts without saved passwords can use cached data before reconnecting manually.
- Keep cached read/unread and follow-up flags consistent with successful changes.

Existing account settings, update preferences and cached messages are preserved.
Older local drafts migrate when Local drafts & delivery is opened. The Linux
NVIDIA/Wayland renderer workaround remains enabled when applicable.

Automated checks cover SMTP uncertainty and copy retries across database reopen,
IMAP command sequences and literal bytes, draft save ordering, offline startup and
window-close failures. Windows x64, Windows x86 and Linux x64 packages are built
and tested in CI before publication. Real-provider integration and Windows GUI
coverage remain separate work; this is still a technical preview.

Still pending: attachments beyond filename listing, safe HTML rendering,
incremental sync/IDLE, multiple active accounts, server-synchronised drafts, CalDAV
synchronisation and storage retention. Sent-copy deduplication cannot eliminate
every race with providers that archive outgoing mail themselves.

Automatic update checks/downloads remain opt-in; installation requires choosing
Install and restart. Downloads include update signatures and SHA256 checksums.
