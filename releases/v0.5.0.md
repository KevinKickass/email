# email 0.5.0

This release adds dark mode, numbered color tags, links directly in formatted
messages and explicit permission to load remote images.

- Choose Light, Dark or System in Settings. The saved theme covers the mailbox,
  calendar, dialogs and HTML reader, and follows system changes automatically.
- Select a message and press 1 (Important, red), 2 (Work, orange), 3 (Personal,
  green) or 4 (To do, blue). Press the same number to remove that tag or 0 to
  remove all four. Matching buttons and badges are also available. Tags use
  Thunderbird-compatible IMAP keywords, survive refreshes and are cached for
  offline display. Changes require a connection and server keyword support.
- Links retain their labels and position inside HTML mail. Hover or keyboard
  focus shows the actual destination; explicit activation opens the default
  browser. The separate destination list remains available.
- A banner identifies blocked remote images and explains the privacy impact.
  Load images for the current message, retry failed downloads or block them
  again. Permission is discarded when switching messages. Requests are made by
  the native loader without browser cookies or referrers; private destinations,
  unsafe redirects and non-raster content are rejected.
- Cached MIME upgrades to the new HTML format locally. Sender scripts, forms,
  frames, external stylesheets/fonts and inline/CID images remain blocked.

Validated with 37 frontend tests, 48 Rust tests, the production frontend build,
formatting checks and Clippy. Browser checks cover inline link activation,
image permission and message switching; the hostile HTML fixture produced zero
automatic resource requests. Signed Windows x64/x86 and Linux AppImage packages
and the updater manifest are published after all GitHub release builds succeed.

This remains a technical preview. Native WebView GUI and real-provider testing,
multiple active accounts, incremental IMAP synchronization and CalDAV
synchronization remain on the roadmap.
