First public preview of **email**, a classic desktop email client.

- Familiar ribbon, folders, message list and reading pane.
- German and English interface with automatic system-language detection and saved language selection.
- IMAP and SMTP with TLS or mandatory STARTTLS, local redb storage and optional CalDAV endpoint probing.
- Signed updates from GitHub Releases. Automatic checks and downloads are off by default; installation happens when you choose **Install and restart**.
- Automatic WebKit DMA-BUF workaround for NVIDIA on Linux.
- Apache-2.0 license.

## Downloads

- **Windows x64:** install `email_0.1.2_x64-setup.exe`.
- **Windows x86:** install `email_0.1.2_x86-setup.exe`.
- **Linux x64:** make `email_0.1.2_amd64.AppImage` executable and run it from a writable location.

The Windows installer can install WebView2 when needed. Download the matching package once to start using the updater; earlier builds without an updater cannot update themselves.

## Preview limitations

Calendar synchronisation, attachment downloads, server-side moves and an IMAP Sent copy are not implemented yet. Email content stays in its original language. This is a technical preview, not yet a production-ready replacement for customer deployments.
