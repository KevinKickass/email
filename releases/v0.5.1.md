# email 0.5.1

- Add Reply all in the toolbar and reading pane. Include Reply-To (or sender),
  To and Cc recipients in the reply draft, removing duplicates and your own address.
- Recover Cc headers from cached MIME for existing messages.
- Accept commas, semicolons and colons as recipient separators in the To field
  and SMTP envelope. Preserve separators inside quoted display names.

Validated with 41 frontend tests, 50 Rust tests, the production frontend build
and Clippy. Signed packages and the updater manifest are published after all
GitHub release builds succeed.
