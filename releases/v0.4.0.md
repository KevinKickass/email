# email 0.4.0

Read formatted HTML mail with a Plain text switch, while keeping images and active
content blocked. Tables, lists, headings, emphasis, quotations and basic inline
colours/alignment are supported.

- HTML is parsed and sanitised in Rust before reaching the WebView, then shown in
  an opaque, scriptless iframe with a separate restrictive CSP. Scripts, forms,
  frames, SVG, remote/data/CID image sources and unsafe CSS are removed or blocked.
- Actual HTTP/HTTPS link destinations appear below the message. Open them explicitly
  in the default browser; sender-controlled navigation inside the reader is disabled.
- HTML-only messages get a readable text conversion for replies and forwards.
  Sender-provided plain-text alternatives are preserved. MIME alternative selection,
  related roots and mixed text sections retain the appropriate message content.
- Cached MIME from 0.3.0 upgrades offline. Older text caches remain readable and need
  an online fetch for HTML. Existing flags, headers and attachment data are preserved.
- Oversized, overly complex or undecodable HTML falls back to text when available,
  with an explanation. HTML input is limited to 2 MiB. Images remain blocked,
  including inline/CID images; attachments can still be saved separately.
- German and English UI, an updated sample mailbox and a reproducible local browser
  privacy fixture for contributors.

Validation covers hostile HTML and CSS, sandbox/CSP configuration, zero resource
probe requests in Chromium, MIME variants, text conversion, offline cache upgrades
and reply/forward content, alongside the existing attachment and delivery tests.

This remains a technical preview. Native WebView GUI and real-provider testing,
incremental IMAP synchronisation, multiple active accounts and CalDAV synchronisation
remain on the roadmap. HTML composition and richer image/CSS support are not included.
